## 🥐 Sobre o projeto

**Le Chef à La Dev** é um cardápio digital interativo inspirado na culinária francesa, desenvolvido com **HTML, CSS e JavaScript puro**.

O projeto simula uma experiência de restaurante moderno com carrinho de compras funcional, controle de quantidade, animações e modo escuro.

---

## ✨ Funcionalidades

- 🥖 Cardápio estilizado com pratos e descrições
- 🛒 Carrinho de compras com `localStorage`
- 🔢 Controle de quantidade antes de adicionar
- 💰 Cálculo automático de total
- 🌙 Modo escuro persistente
- 🔔 Feedback visual ao adicionar itens
- 🍷 Checkout com animação de confirmação
- 🔊 Som de confirmação de pedido
- 📱 Interface responsiva estilo app de delivery

---

## 🧠 Objetivo

Projeto criado para praticar:

- Manipulação do DOM
- Estado no navegador (localStorage)
- Lógica de carrinho de compras
- UX/UI inspirada em apps reais (iFood / Uber Eats)
- Organização de código front-end puro
